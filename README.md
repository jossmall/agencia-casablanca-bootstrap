# Agencia Casablanca

Sitio web responsive para una agencia inmobiliaria ficticia, desarrollado como proyecto de Diseño de Interfaces Web (DIW).

El proyecto utiliza HTML, CSS y Bootstrap para crear una web adaptable a diferentes tamaños de pantalla.

## Funcionalidades

- Diseño responsive con Bootstrap
- Navegación entre diferentes secciones
- Galería de viviendas
- Carrusel de imágenes
- Formulario de contacto
- Efectos CSS mediante hover y transformaciones
- Portada disponible en español e inglés

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5

## Páginas

- Inicio
- Venta de viviendas
- Conócenos
- Contacto
